# The Impact of Natural Disasters on the Japanese Stock Market

## Introduction

This project examines the impact of natural disasters on the Japanese stock market, with a focus on the Nikkei index and three key sectors: insurance, transportation, and utilities.

Using ARMA-X and GARCH models, the analysis studies both the immediate (first-order) and subsequent (second-order) effects of natural disasters on stock market behaviour. The objective is to better understand how these events affect market dynamics, with particular attention to volatility patterns across sectors.

## Project Structure

### 1. Project workflow

To run the project:

- Place all scripts and datasets in the same working directory.  
- Open the main script in your statistical software.  
- Ensure the working directory is correctly set.  
- Run the scripts in the required order to reproduce the analysis.  

### 2. Methodology

The project is based on two main econometric approaches:

- **ARMA-X models**: used to assess the effect of natural disasters on stock market returns while controlling for time-series dynamics.  
- **GARCH models**: used to analyse how natural disasters affect stock market volatility over time.  

The analysis focuses on:

- The **Nikkei index**
- The **insurance sector**
- The **transportation sector**
- The **utilities sector**

### 3. Research objective

The aim of the project is to evaluate whether natural disasters influence stock price levels and volatility in the Japanese market, and whether these effects differ across sectors.
